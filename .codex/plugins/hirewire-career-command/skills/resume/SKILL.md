# Resume

Use the canonical resume production standard in `.claudex/skills/resume/SKILL.md`.

## Codex popup behavior
Expose this skill in the Codex plugin/skills popup as **Resume** with invocation `/resume`.

## Ownership
This skill exclusively owns resume layout, typography, margins, spacing, page utilization, chronology, ATS safety, employer-safe content, and visual QA.

## Required modes
- `/resume build <job>`
- `/resume audit <file-or-folder>`
- `/resume rebuild <range>`
- `/resume verify <file-or-folder>`

## Hard gate
Never release a resume that contains RedLantern Studios or HireWire visual branding, internal evaluation, tiny text, excessive empty space, incomplete career progression, merged Ingram roles, weakened loanDepot leadership context, or unverified claims.
