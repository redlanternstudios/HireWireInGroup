Problem: Multiple files were importing a non-existent createClient export from /lib/supabase/client.ts, causing build failures.

Root Cause: The Supabase client file exports a singleton supabase instance and useSupabase() hook, NOT createClient().

Files Fixed:

  • app/(auth)/signup/page.tsx - Import createClient from @supabase/supabase-js
  • app/(auth)/login/page.tsx - Import createClient from @supabase/supabase-js

Resolution: All Supabase imports now follow the correct pattern. Build errors eliminated.
